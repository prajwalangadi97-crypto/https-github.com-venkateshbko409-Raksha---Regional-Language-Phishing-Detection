## 📌 Executive Summary

Cyber fraud in India has evolved past traditional English email scams into sophisticated, highly localized attack vectors operating across **regional languages (Kannada, Telugu, Tamil, Hindi)**, instant messaging platforms (WhatsApp, Telegram), and direct voice spoofing.

In Karnataka alone, over **₹1,200+ Crores** are lost annually to cyber syndicates executing:
1. **BESCOM Electricity Disconnection Scams** (*"ಇಂದೇ ರಾತ್ರಿ ವಿದ್ಯುತ್ ಸಂಪರ್ಕ ಕಡಿತಗೊಳ್ಳಲಿದೆ..."*)
2. **CBI / Mumbai Police Video Call "Digital Arrest" Extortions**
3. **Predatory Instant Loan App Blackmail** with contact book exfiltration
4. **SBI YONO / Aadhaar / Pan Update Smishing**
5. **AI Voice Clone Family Kidnapping & Emergency Calls**
6. **Fake Reverse UPI / QR Code Merchant Scams**

**Omnikon — Raksha AI** is an end-to-end, multi-layered cyber defense ecosystem engineered specifically to protect citizens, enterprises, and law enforcement agencies with real-time heuristic triage, deep learning classification, forensic analysis, and emergency response workflows.

### 1. 🔍 Indic NLP & Multimodal Vision Phishing Engine
- **Kannada & Regional Language Heuristics**: Analyzes native Kannada script, Romanized Kannada (*Kanglish*), and mixed Indic dialects to detect coercive triggers (panic, artificial urgency, authority impersonation, shame threats).
- **Automated Entity & IOC Extraction**: Identifies suspicious URLs, unverified UPI IDs, phone numbers, and Telegram links.
- **Screenshot OCR Analysis**: Processes MMS/WhatsApp screenshots, extracting embedded text and evaluating image-based phishing lures.

### 2. 🎙️ Acoustic Voice Deepfake & AI Clone Forensics
- **Spectral Jitter & Respiration Analysis**: Inspects vocal tract acoustics, respiration anomalies, and neural vocoder artifacts to distinguish synthetic cloned voices from genuine human speech.
- **Live Microphone Capture**: Allows victims to record suspicious incoming extortion calls in real-time for immediate forensic scoring.
- **Family Safe Word Protocol**: Generates offline cryptographic challenge words for families to counter AI voice kidnapping scams.

### 3. 🚨 1930 NCRP Golden Hour Emergency Freeze
- **Critical 2-to-3 Hour Protocol**: Empowers victims of financial fraud to immediately lock compromised payment gateways before mule transfer layering occurs.
- **Automated Bank Notice Generator**: Produces legally formatted notice templates for SBI, HDFC, ICICI, Canara Bank, and payment apps (PhonePe, GPay, Paytm) citing RBI Circulars and IT Act sections.
- **Direct Dial 1930 Emergency Integration**: 1-tap connection to the National Cyber Crime Reporting Portal helpline.

### 4. 📍 Karnataka CEN Police Station Locator & FIR Generator
- **Complete 31-District Directory**: Detailed directory of all Cyber Economics & Narcotics (CEN) police stations in Karnataka with phone numbers, emails, addresses, and nodal contacts.
- **GPS Proximity Routing**: Automatically locates the nearest CEN station based on victim coordinates.
- **Formal Legal FIR Petition Generator**: Pre-fills official complaint drafts citing IT Act Sections 66C, 66D, IPC Sections 419, 420 with transaction UTRs and scammer contacts.

### 5. 🤖 Autonomous AI Honeypot Syndicate Trap
- **Adaptive Persona Simulation**: Engages scammers with conversational personas (naive retiree, eager investor, student) to keep fraudsters on the hook.
- **Mule Account Harvester**: Extracts scammer bank account numbers, IFSC codes, and UPI handles and feeds them into law enforcement watchlists.

### 6. 📦 Sideloaded APK Malware Sandbox
- **Permission & Manifest Decompiler**: Analyzes high-risk Android permissions (`READ_SMS`, `BIND_ACCESSIBILITY_SERVICE`, `READ_CONTACTS`, `SYSTEM_ALERT_WINDOW`).
- **C2 Domain & Loan Harvester Detection**: Flags predatory loan app frameworks and spyware communicating with foreign command-and-control servers.

### 7. 🗺️ Karnataka Live Cyber Threat Map & Radar
- **District Telemetry Heatmap**: Real-time visualization of cyber threat incidents across Bengaluru Urban, Mysuru, Mangaluru, Belagavi, Hubballi-Dharwad, and all Karnataka districts.
- **Smishing Surge Detection**: Live tracking of localized attack waves and archetype surges.

### 8. 🛡️ Senior Citizen Voice Protection & High-Contrast Mode
- **Accessible Design System**: Extra-large touch targets, high-contrast visual cues, and full Kannada audio guidance designed specifically for elderly citizens vulnerable to digital arrest threats.

## 🚀 Quick Start Guide

### Prerequisites
- **Node.js** >= 18.0.0
- **Python** >= 3.10
- **npm** or **pnpm**

---

### 1. Clone the Repository
```bash
git clone https://github.com/prajwalangadi97-crypto/https-github.com-venkateshbko409-Raksha---Regional-Language-Phishing-Detection.git omnikon
cd omnikon
```

### 2. Frontend Setup
```bash
# Install frontend dependencies
npm install

# Run Vite development server (Port 3000)
npm run dev

# Build for production
npm run build

# Run Oxlint verification
npm run lint
```

### 3. Backend Setup
```bash
# Navigate to project root and install Python dependencies
pip install -r backend/requirements.txt

# Start the FastAPI server (Port 8000)
python -m uvicorn backend.main:app --reload --port 8000
```

The application will be accessible at:
- **Frontend Dashboard**: `http://localhost:3000`
- **Backend API & Swagger Docs**: `http://localhost:8000/docs`
- **Health Check Endpoint**: `http://localhost:8000/health`

## 🔒 Security, Privacy & Responsible AI

1. **Client-Side Privacy Preservation**: Sensitive data (such as victim bank accounts, phone numbers, and FIR personal details) are generated locally in memory or anonymized before transmission.
2. **Zero Permanent Voice Storage**: Audio samples processed in the voice forensic sandbox are analyzed in transient buffers and immediately discarded after acoustic feature extraction.
3. **Law Enforcement & Citizen Safety**: Generated formal complaints are formatted in strict compliance with the **Information Technology Act, 2000** (Sections 43, 66C, 66D) and **Indian Penal Code** (Sections 419, 420), providing actionable evidence for cyber investigators.
